# Illustrator CAD Cleaner v1.3

Windows 11 + Illustrator 2026용 단일 JSX 업데이트입니다. 첨부된 v1.2를 기준으로 수정했습니다. 별도 Python 설치가 필요하지 않습니다.

## 실행

1. ZIP을 풀고 Illustrator 문서를 **다른 이름의 사본으로 먼저 저장**하세요.
2. Illustrator 메뉴 **파일 > 스크립트 > 기타 스크립트**에서 `CAD_Cleaner_v1.3.jsx`를 선택합니다.
3. 처음에는 일부 선만 선택하고 기본 옵션으로 **1. 검사 / 예상**을 실행하세요. 이 단계에서는 문서를 변경하지 않습니다.
4. 결과에 변경 대상이 있으면 **2. 정리 실행**을 누릅니다. 검사가 끝난 설정 창은 적용 전 예상 결과를 보여 주는 창입니다. 실제 적용 전까지는 남아 있는 것이 정상입니다.
5. 실제 정리가 끝나면 진행 제어창이 닫히고 **정리 완료 / 안전 중단 / 오류 확인 필요** 결과를 표시합니다. 정리할 대상이 전혀 없으면 검사 창도 닫히고 원본 변경이 없다고 알립니다.
6. 정리 결과를 확인한 뒤 새 이름으로 저장하세요. 스크립트는 문서를 자동 저장하거나 원본 파일을 덮어쓰지 않습니다.

v1.2 작업이 아직 실행 중이라면 먼저 기존 제어창의 **재개 → 안전 중단**으로 종료한 뒤 v1.3을 실행하세요. 새 파일은 이미 실행 중인 v1.2 프로세스를 변경하지 않습니다.

## 이번 수정

- 완료 후 PAUSE 신호를 읽어 무한 대기하던 경로를 제거했습니다. 마지막 실제 작업 뒤에는 일시정지 대기에 들어가지 않습니다.
- 성공·중단·오류 모두 `finally`로 제어창 종료 신호를 보냅니다. 완료 플래그와 종료 상태를 별도로 처리하고, 닫힘 확인은 최대 1.2초만 기다립니다. 제어창 X도 닫기를 막지 않습니다(작업 중이면 중단 요청).
- 외부 제어창이 실제로 표시된 후에만 작업을 시작합니다. 제어창이 닫히거나 heartbeat가 8초 이상 끊기면 다음 확인 지점에서 안전 중단합니다.
- 진행 표시 파일을 4개 객체마다 강제로 읽고 쓰던 방식을 없애고 시간에 따라 통신합니다. CPU 양보도 시간 기준으로 제한합니다.
- 같은 좌표라도 그룹·레이어·획 스타일이 달라 비교할 필요가 없는 항목을 먼저 분리합니다. 밀집 연결 후보는 검사량 한도에 도달하면 **전체 연결 판단을 보류**합니다.
- 한 재구성은 최대 64개 원본·4,000앵커로 제한합니다. 새 패스의 앵커뿐 아니라 곡선 핸들도 검증한 후 원본을 삭제합니다.
- 원본 삭제나 미완성 복제본 제거가 실패하면 성공으로 숨기지 않고 오류와 잔여 중복 가능성을 알립니다.
- 결과 숫자는 완료된 재구성을 기준으로 표시합니다. 분석 예상치를 실제 완료 수처럼 표시하지 않습니다.

## 빠른 기본값과 한도

기본 ON: 중복선, 0 길이/1점 찌꺼기, 불필요한 직선 앵커.

기본 OFF: 끝점 연결, 빈 그룹 검사, 곡선 근사. 필요할 때 켤 수 있습니다. 연결과 구조 정리는 도면에 따라 비용이 커서 기본값을 변경했습니다.

- 끝점 연결 거리: **mm 단위**, **0.001mm 단위 입력**. 기본 0은 좌표가 정확히 같은 끝점만 연결합니다. 곡선 근사 오차는 기존처럼 pt 단위입니다.
- 최대 20,000패스 / 총 120,000앵커 / 단일 패스 4,000앵커. 복잡한 단일 패스는 잘라 바꾸지 않고 제외합니다.
- 분석·적용·미리보기 각 단계에 45초 작업 한도를 둡니다. 사용자 일시정지 시간은 제외합니다. 한도는 **다음 확인 지점에서** 적용되므로 정확한 실행시간 상한은 아닙니다.
- 분석이 중단되면 문서를 바꾸지 않습니다. 적용 도중 중단하면 완료된 작업만 남습니다. 남은 범위는 작게 나눠 다시 검사하세요.
- 한도로 전체 범위를 분석하지 못한 경우 불확실한 연결을 만들지 않도록 연결 검사를 보류합니다. 다른 정리의 일부 결과는 적용 가능할 수 있으므로 결과 숫자를 확인하세요.
- 곡선 근사는 선택한 개체만, 최대 30패스·패스당 400회 후보 검사입니다. 미리보기는 최대 5예시입니다.

## 응답 없음과 복구의 현실적인 한계

**이 스크립트는 Illustrator 내부에서 동기 실행됩니다.** 외부 Windows 창이 클릭에 반응하는 것과 Illustrator가 자유롭게 편집 가능한 것은 다릅니다. Adobe의 `duplicate`, `setEntirePath`, `remove` 같은 개별 호출은 반환되기 전까지 JSX가 중단할 수 없습니다. 따라서 모든 도면에서 PC 다운이나 응답 없음이 절대 생기지 않는다고 보장할 수 없습니다. 계산/객체 크기 한도로 위험 구간을 줄였습니다.

대형 CAD 도면은 전체 문서보다 선택 범위를 나눠 작업하세요. 중단 후 별도의 선택 상태 체크포인트를 만들어 재개하는 기능은 없습니다. 완료된 변경은 현재 문서에 남으므로 다시 검사하면 됩니다.

자동 독립 백업을 만드는 버전은 아닙니다. 실행 전에 사본 저장이 필요합니다. 일반 JSX는 Ctrl+Z 한 번으로 전체 복구를 보장하지 않습니다. 원본 파일은 자동 저장하지 않으므로 실행 전 저장한 사본으로 복구할 수 있습니다.

PowerShell/VBScript 실행을 회사 보안 정책이 막으면 제어창 확인 후 작업을 취소합니다. 보안 제품을 끄거나 정책을 우회하라는 뜻은 아닙니다. 제어창 시작 실패 시 관리자에게 허용된 실행 방법을 확인하세요.

## 검증 범위

- Node 호스트 어댑터 테스트 32개 통과: 최종 PAUSE, 제어창 닫힘/heartbeat 단절, 상태 통신 억제, 실제 스크립트 전체 검사→적용 흐름, 변경 없음 종료, 원본/복제본 제거 오류, 중복·곡선 핸들·분기·평행선·0거리·밀집/긴 체인 보호.
- Acorn의 ES3 모드로 실제 배포 JSX 전체 문법 검사 통과.
- 기존 별도 DXF 프로그램의 Python 테스트 17개도 통과.
- 생성된 PowerShell 제어창 로직(상태 파일 잠금에도 완료 처리, 종료 상태 대체 경로, X→STOP) 검사용 Windows CI를 추가했습니다. 이 클라우드에서는 실행하지 못했으며 CI 결과와 실제 PC 확인이 필요합니다.

**Windows PowerShell/WinForms 및 Illustrator 2026을 이 Linux 환경에서 직접 실행하지 못했습니다.** 위 테스트는 Adobe의 실제 객체 API, 실제 도면의 표시와 속도까지 검증한 것이 아닙니다. 사본의 작은 선택 범위에서 먼저 확인하세요. Illustrator에서 측정한 속도 향상 수치는 제공하지 않습니다.

개발 검증 명령: `npm ci --ignore-scripts` 후 `npm run test:jsx`.
